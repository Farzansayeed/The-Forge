# The Forge — Full App Audit · 2026-10-26

Three-lens audit of the production app: (1) live walkthrough as a first-time user with agent-browser
(onboarding → daily tracking → quizzes → close-day, both themes, mobile 390×844, offline SW test on
the live site, reduced-motion emulation, axe-core, network + vitals), (2) developer-lens code audit,
(3) design-system + motion code audit. Every code finding verified at file level; every UX finding
reproduced in a real browser. Companion execution contract: **`FIXPLAN.md`**.

## 🔴 Ship-blockers

### 1. Verdict modal "orphan scrim" — ❌ RETRACTED 2026-10-26 (was live-repro'd, could not stand)
> **Truth-up:** controlled re-repro during WS1 (FIXPLAN) disproved the mechanism. `Modal` renders
> scrim + dialog as one conditional subtree (`if (!open) return null`, `Modal.tsx:56`) — they cannot
> separate. Three controlled real-mouse body clicks on the open verdict dialog left the state
> **invariant** (`dialogs:1, scrims:1`); the content in the originally captured "stuck" state had
> `opacity:1` and both its buttons visible — i.e. it was a legitimately open modal whose sanctioned
> exits (dialog buttons, Esc, scrim ring — all three verified leaving `dialogs:0, scrims:0` on the
> fixed build) were missed in the walkthrough moment. The "app click-dead" reading was the scrim
> correctly intercepting clicks *outside* an open dialog.

What the investigatation DID surface — two real defects in the same component, both fixed in WS1:

- **Focus-trap churn:** the trap effect listed `onClose` as a dependency while every call site passes
  an inline arrow (new identity per parent render) — any parent re-render while the modal was open
  tore down + reinstalled the document keydown listener and re-ran focus juggling
  (`restoreRef.focus()` → first-focusable). Fixed by reading the callback through a ref at event
  time; deps are now `[open]` (`src/components/ui/Modal.tsx`).
- **Theme-blind scrim:** hardcoded `rgba(4,6,10,0.6)` (`Modal.tsx:70`) rendered a near-black void in
  Blueprint (light). Now `var(--scrim)` — `rgba(4,6,10,0.6)` in terminal (shipped look preserved
  verbatim), `rgba(26,34,51,0.35)` ink veil in blueprint (`src/styles/tokens.css`).

Verification record (agent-browser, WS1 session): both themes' verdict dialog screenshotted; dismissal
paths A (scrim ring tap) / B (Esc, focus restored to "✦ Close the day") / C (confirm button) each leave
zero dialogs and zero fixed scrims; console clean; typecheck + 94/94 tests + build green.

### 2. One corrupt localStorage blob silently destroys all user history
`src/lib/storage.ts:62-72` — `loadData()` routes any parse/validation/migration failure into
`persistDefault()`, which **immediately writes fresh defaults over the same key**. A malformed blob
(partial write, bad extension, bug) permanently erases months of ledger data. Fix ≈3 lines: stash the
offending payload under a `.bak` key before resetting.

### 3. UTC-vs-local date bug class — 8 sites
All compute the date via `new Date().toISOString().slice(0, 10)` (UTC) while the ledger keys days by
local `todayKey()` (`src/stores/daily.ts:4,14`). During evenings/mornings west or east of UTC, roasts,
dread level, tribunal, quiz review and Arena all reference a *different* day than the ledger recorded.
- `src/features/dread/RoastOverlay.tsx:29`
- `src/features/dread/DreadProvider.tsx:15`
- `src/features/dread/BedtimeLockout.tsx:24,49` (merges a UTC date with a local bedtime compare)
- `src/features/today/TodayPage.tsx:445`
- `src/features/stats/StatsPage.tsx:237`
- `src/features/dread/TribunalCard.tsx:88`
- `src/stores/quiz.ts:49`
- `src/features/arena/ArenaPage.tsx:89`

Fix by routing every consumer through local `todayKey()`; add midnight + `visibilitychange` refresh
to `useDaily` (today is computed once at store creation, `daily.ts:42-48,105`).

### 4. `--faint` fails WCAG AA in BOTH themes, ~40+ call sites
`src/styles/tokens.css:24` (dark `#5c6473` on `#11151d` ≈ **2.98:1**) and `tokens.css:68`
(light `#8b94a8` on white ≈ **2.98:1**, on `--bg` ≈ 2.64:1). It is the default metadata color:
section headings, mono eyebrows, heatmap month labels, quiz code-lines — at 8.5–13px.
Measured live: h2/eyebrow `rgb(92,100,115)` on `rgb(11,14,20)` = **3.24:1**; axe-core flags 5 nodes on
Today alone. Related: light-theme phase accent `--p5: #9a7d1f` (`tokens.css:84`) ≈ 3.94:1 on white at
12px text.

## UX & workflows (user lens)

**Verified working:** onboarding flow (5 steps, spicy + Terminal preselected, finale CTA); persistence
across reloads (topics 1/5, hours 67%); boss gate attemptable cold at 0% progress; quiz WHY-panel
after misses is the best teaching surface; verdict honesty ("Pass — I put in the work / Fail — the day
beat me"); Postpone modal implements U6 exactly (Valid / Invalid excuses / Write your own, "Keep
studying" pinned primary); roadmap topic state mirrors into Today instantly (S00 ticked on Today shows
1/12 + 8% ring on Roadmap without reload); Diagnostics page self-validates the ledger (19 stages · 230
items · 379 quiz items · 4 boss exams · 86-day schedule; mirrors CI validator).

**Findings:**
- ~~🔴 Scrim leak (blocker #1)~~ — **retracted during WS1** (see blocker §1 truth-up); the two real
  Modal defects it hid (trap churn on parent re-render, theme-blind scrim) are fixed.
- 🟠 **Scroll never resets across route changes** — verified: Today scrolled to 542px → click
  Roadmap → land mid-list at 542px. No `ScrollRestoration`/scroll-to-top in `src/app/App.tsx` routes.
  Inconsistent: some navigations landed at 0, others inherited scroll — so the bug class is
  "no explicit scroll contract".
- 🟠 **Boss-quiz header scrolls behind the sticky topbar** — in a long question (Find-the-Bug), the
  quiz eyebrow/title/‹/Leave-quiz row is clipped under the sticky nav; mid-question the exit
  affordance is invisible, and Playwright-style click interception reproduces the user experience
  ("covered by sticky header"). Screenshot evidence: `audit-quiz2.png`.
- 🟠 **Focus timer does not survive refresh** — verified live: clock at 00:27 running → reload →
  00:00 with Start reset. Minutes only bank via explicit "✓ Log". Accidental refresh loses the whole
  session. (U7 fail.)
- 🟡 **Verdict copy contradicts the ledger** — screenshot shows roast "Target smashed. Streak alive.
  Future self just exhaled." directly above "TARGET MISSED (2h / 3h) — PASS, BUT THE LEDGER
  NOTICED." Template assumed target-hit.
- 🟡 **Three competing length numbers**: onboarding card says "A 23-week C × DSA curriculum"; the
  schedule engine built **86 days** (Diagnostics: study 74 + sunday 12, first 2026-10-26); "Planned
  finish Jan 19, 2027" (~85 days). Also Roadmap header counts "1/230 items" vs Stats "Topics
  completed 1/6034" without labeling the difference. Diagnostics shows "· 1 days · 1 checks"
  (pluralization bug).
- 🟡 **Intro auto-passes (~2 s) while saying "CLICK TO SKIP"** and replays on every full load.
- 🟡 Onboarding dialog does not auto-focus its first control (focus starts on `body`; Tab order works;
  U8 trap works while open).
- 🟡 Feedback thinness: no toast/live feedback on hours or ✓ Log; single `aria-live` region exists but
  stayed empty; after close-day only the button changing to "⟲ Reopen day" (plus the line "Verdicts
  are permanent in spirit. This one isn't.") signals success.
- 🟡 Onboarding scrim deliberately blocks all clicks until finished/skipped (correct), but Escape does
  nothing — acceptable, noted.

## Design (designer lens)

**Good bones:** single `src/styles/tokens.css` with two `data-theme` palettes + composable
`[data-dread]` layer; near-total color token discipline; one easing signature `[0.25,0.9,0.35,1]`.

**Findings:**
- 🔴 `--faint` AA fail (blocker #4).
- 🟠 **389 inline `style={{…}}` objects across 22 files** while Tailwind v4 is imported and used in
  only 2 spots (`SpotlightCard.tsx:69`, `RoadmapPage.tsx:81`). Verified consequence: **zero
  `:hover`/`:active` selectors exist in src** — every button is visually inert until click. Inline
  styles cannot express media queries or `:focus-visible` (SpotlightCard hand-duplicates focus logic
  via `onFocus/onBlur`).
- 🟠 The promised component layer was never built: DESIGN.md §6 Spring `Checkbox`, Button, Card
  patterns, a 6-step type scale — instead four divergent `btn()` factories
  (`TodayPage.tsx:16`, `src/features/arena/shared.tsx:5`, `SettingsPage.tsx:15`, `Onboarding.tsx:20`)
  and bare native checkboxes with `accentColor` in 5 places.
- 🟠 **25 distinct font-size values** vs the 6-step contract (12/13/15/18/24/34) — from 8.5px
  (`TribunalCard.tsx:172`) to 40px (`BedtimeLockout.tsx:160-161`).
- 🟠 **10 headings request Space Grotesk 800, which is not loaded** (`index.html:15` loads only
  400–700) → browser synthesizes faux-bold on the most important headings.
- 🟡 "Claymorphic" is name-only in v3: `--shadow-1/-2` never used, no tactile inset-highlight tokens,
  11 distinct radii (4…99), same `border 1px var(--border) + var(--panel)` recipe copy-pasted ~25×.
- 🟡 Emoji/unicode icon roulette (🔥 ☀ ⚔ 🛡 💤 ✦ ✖ ⟲ ↺ ▦) while purpose-built tintable
  `src/app/AnvilMark.tsx` is dead code (no importers).
- 🟡 Modal scrim hardcoded theme-blind (`Modal.tsx:70`) vs `color-mix` scrims elsewhere. *(fixed in
  WS1 — now `var(--scrim)`, theme-native in both palettes)*
- 🟡 Mobile sticky chrome ≈ **90px** (56px brand row + 34px scrollable nav row with no edge fade) vs
  U4's 56px contract; brand tagline truncates mid-word ("THE TRACKER FIG…" without ellipsis).

## Developer (code lens)

**Clean:** TypeScript strict, zero `any`/`@ts-ignore`/console leaks; no unused deps; disciplined
cleanup; excellent IntroGate test coverage including the resurrection regression; 94/94 tests green.

**Findings:**
- 🟠 Failed writes are swallowed **and the pending buffer is consumed anyway** (`storage.ts:16-25`) —
  silently lost work under quota/private-mode failures.
- 🟠 Persistence is hand-rolled per store instead of the documented "Zustand (+persist)" abstraction
  (`daily.ts:6-10`, `progress.ts:11-15`) — each repeats load/parse/save with the same failure modes.
- 🟠 v2 import leaves the checked-mirror store stale until a reload (`SettingsPage.tsx:94-103` vs
  `progress.ts:17-18`).
- 🟠 **SW `activate()` never prunes same-version caches** (`public/sw.js:26-39`) — with Vite hash
  churn per deploy, ASSET_CACHE grows unbounded on long-lived devices; SWR background refresh not
  wrapped in `event.waitUntil` (`sw.js:89-96`); registration failure silent (`index.html:24-31`,
  `.catch(() => {})`), and the gate excludes even localhost.
- 🟠 **Entry bundle 459.01 kB (gzip 150.51) carries the full curriculum data** — quiz corpus correctly
  split (async chunk 201.31 kB / 65.73 gz, verified absent from entry), ElectricLogo (ogl, 71.97 kB)
  correctly lazy; curriculum `concept` strings and Today's heavy sub-components should get the same
  treatment.
- 🟠 **Zero tests on the store layer** — highest-risk code (rollover semantics, patch/save races)
  untested; refactors planned here need characterization tests first.
- 🟠 react-router-dom 6.x carries two moderate advisories (incl. open-redirect GHSA-wrjc-x8rr-h8h6) —
  fix is the scoped 6→7 migration.
- 🟡 O(n²) heatmap positioning (`StatsPage.tsx:141`, ~133k comparisons for 365 cells).
- 🟡 Invalid HTML: `<button>` nested inside `<a target="_blank">` (`renderers.tsx:434-435`) — render
  the `<a>` styled as the button instead.
- 🟡 Arena stage-set accent derived by string-munging that never matches
  (`ArenaPage.tsx:203`: `.replace('s0','p')` no-op chain) — per-set accents effectively dead.
- 🟡 Settings commits persistence + schedule rebuild on **every keystroke**
  (`SettingsPage.tsx:67-74,130`; empty input coerces to defaults via `Number(...) || 3`).
- 🟡 Cold start parses the persisted blob N times (one per store; `progress.ts:18` twice).
- 🟡 Dead code: `src/components/bits/DecryptedText.tsx`, `src/app/AnvilMark.tsx` (zero importers).
- 🟡 Docs drift (worse than cosmetic because claims assert acceptance): DESIGN.md:262 says U1–U15
  "**accepted**" while Reset doesn't exist (`SettingsPage.tsx:12`: "Reset arrives with Phase 7"); §3.3
  `ReviewCard {interval,reps}` vs shipped `{step,lastAt}` (`schema.ts:39-48`); §4 theme
  `'terminal'|'blueprint'|'system'` vs two-value enum (`schema.ts:9`); palette quick-actions
  (toggle/start/close-day) promised at `DESIGN.md:166`, only nav + toggle-theme shipped
  (`CommandPalette.tsx:50-83`); embedded fix-code editor at `DESIGN.md:159` vs shipped deep-link
  (`renderers.tsx:426-479`); title says "(v3)" while `SCHEMA_VERSION = 4` (`schema.ts:6-7`).

## Animations (motion lens)

23 motion surfaces catalogued (WebGL intro, route slides, stage height-expand, CountUp spring, roast
toast skew, bedtime lockout pulse, dread glitch, Lenis, theme fade, scramble text, spotlight). Feel is
coherent — one easing signature, short durations, no janky staggers. High-intensity effects (Lenis,
WebGL, roast/bedtime/onboarding overlays, glitch) DO respect reduced motion (~9 hand gates).

- 🟠 **motion/react engine is not reduced-motion-aware** — no `<MotionConfig>` anywhere; route
  transitions (`App.tsx:47-52,184`), stage height-expand (`RoadmapPage.tsx:124-130`), chevron
  (:113-118), CountUp (:177), Arena runner mount (`ArenaPage.tsx:94`) all animate under reduced
  motion. The CSS kill at `tokens.css:185-193` only neutralizes CSS transitions. Live-verified: under
  emulated `prefers-reduced-motion: reduce`, CSS durations collapse to 1e-05s (working) but the
  engine's pipeline still slides.
- 🟠 **4 of 9 routes animate, 5 don't** (`App.tsx:189-214`) — `/viz /stats /library /settings
  /diagnostics` bare `<Route>`s vs `pageMotion` wrappers elsewhere; Arena hub↔runner swap declares a
  dead `exit` prop with no surrounding AnimatePresence (`ArenaPage.tsx:94`); Modal has zero animation
  (`Modal.tsx:56-60`) while sibling overlays fade.
- 🟠 **SpotlightCard re-renders React per mousemove** unthrottled; Roadmap mounts 19
  (`SpotlightCard.tsx:25-29, 203-211`).
- 🟡 Layout-affecting transitions: hours/quiz bars animate **width** (`TodayPage.tsx:159`,
  `QuizRunner.tsx:153`) → use `scaleX`; stage detail `height: 0→auto` expand is the heaviest.
- 🟡 Signature `[0.25,0.9,0.35,1]` hand-copied 5×; durations 0.18/0.2/0.22/0.25/0.3/0.4/0.5 vs
  contract's 150/250/400.
- 🟡 `AnimatePresence mode="wait"` + cold lazy chunk = 180ms exit + fallback paint + 180ms entrance
  (400–600ms void showing "the forge opens…" on first visit to Arena/Roadmap).
